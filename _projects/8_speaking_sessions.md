Delivered a member session at GDGoC Ewha on building and maintaining a developer portfolio using GitHub Pages (github.io). Covered the full workflow from repository setup to deploying a Jekyll-based academic site, with practical guidance on structuring project showcases for both developers and recruiters.

Conducted an internal Git & GitHub workshop for the SDIJ Forest Team's lecture analysis team to support smooth collaborative LRS (Learning Record Store) development. Designed for teammates approaching version control from a "Vibe Coder" perspective — prioritizing practical, immediately applicable workflows over theory.

**Topics covered:**

- Core Git concepts: commits, branches, and merge strategies
- Collaborative GitHub workflows for multi-member teams
- Resolving common conflicts in shared codebases (e.g., shared schema files)
- Best practices for team-based software development

## Korean LLM Benchmark Evaluation

**Jan. 2026 | Python, OpenAI API, Google Gemini API | Independent Evaluator**

### Overview

Engineered an automated evaluation pipeline to systematically assess the Korean language capabilities and cost-efficiency of 6 production LLMs across 4 high-difficulty Korean NLP benchmarks. Delivered a comprehensive corporate report on model capability and cost-efficiency to guide deployment decisions.

### What I Built

- **LLM-as-a-Judge Scoring Pipeline**: Automated evaluation framework using LLM-based scoring with regex extraction for structured result parsing
- **Multi-Model Evaluation**: Assessed 6 production LLMs including models from OpenAI and Google across diverse Korean NLP task types
- **Benchmark Coverage**: Evaluated across 4 high-difficulty Korean NLP benchmarks spanning reasoning, comprehension, and language understanding
- **Cost-Efficiency Analysis**: Produced comparative analysis of performance-per-cost across all evaluated models

### Key Results

- Evaluated **6 production LLMs** in a single automated pipeline
- Covered **4 high-difficulty Korean NLP benchmarks**
- Delivered corporate report directly informing model selection and deployment strategy

### Technologies

**APIs**: OpenAI API, Google Gemini API
**Implementation**: Python, regex-based result extraction
**Evaluation Framework**: LLM-as-a-judge scoring methodology
